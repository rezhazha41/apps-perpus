# Perpus Android

Fondasi aplikasi perpustakaan anggota/admin. Build saat ini menggunakan data demo dalam memori, tanpa koneksi backend.

Jalankan `flutter pub get` lalu `flutter run` dari direktori ini. Lihat [panduan pengembangan](../../docs/development.md), [status implementasi](../../docs/implementation-status.md), dan [PRD](../../README.md).
